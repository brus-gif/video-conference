# MeetingGrid 信令协议 v0.1.0

> 服务端：`server/`（`MeetingGridServer.exe`，C++/Qt `QWebSocketServer`）。
> 所有消息均为 **JSON 文本帧**，UTF-8 编码，统一信封 `{"type":"...", ...}`。

## 连接

- 地址：`ws://<host>:8090`（默认端口 8090，`--port` 可改）。
- 建连后服务端立即下发：

```json
{"type":"hello","version":"0.1.0"}
```

## 客户端 → 服务端

| type | 字段 | 说明 |
|------|------|------|
| `create_room` | `name` (string) | 主持人创建房间 |
| `join_room` | `room_id` (string), `name` (string) | 加入房间（`room_id` 会忽略空格/短横线） |
| `leave_room` | — | 主动离开当前会议 |
| `set_state` | `mic`? (bool), `cam`? (bool) | 更新麦/摄像状态，**只传变化字段** |
| `set_share` | `on` (bool) | 共享屏幕开/关 |
| `chat` | `text` (string) | 发送聊天消息 |
| `ping` | — | 心跳（服务端回 `pong`） |

## 服务端 → 客户端

| type | 字段 | 说明 |
|------|------|------|
| `hello` | `version` | 连接建立后立即下发 |
| `room_created` | `room_id` | 创建成功（发给主持人） |
| `joined` | `room_id`, `member_id`, `members[]` | 入会成功（发给本人，`members` 为房间全量列表） |
| `member_joined` | `member` | 广播：有新成员加入 |
| `member_left` | `member_id` | 广播：有成员离开 |
| `member_updated` | `member_id`, `mic`, `cam`, `sharing` | 广播：成员状态变化（麦/摄像/共享） |
| `chat` | `member_id`, `name`, `text` | 广播：聊天消息 |
| `room_closed` | — | 广播：房间已关闭（主持人离开或房间空） |
| `error` | `code`, `message` | 发给单个客户端（入会失败等） |
| `pong` | — | `ping` 的回复 |

## member 对象

```json
{"id":"m1","name":"张伟","mic":true,"cam":true,"sharing":false,"isHost":false}
```

## 服务端行为

- 房间号：9 位数字（客户端可显示为 `"882 536 419"`，发消息时用连写 `"882536419"` 即可）。
- 房间上限 **49 人**；主持人 = 创建者。
- **主持人离开 或 房间空** → 广播 `room_closed` 并销毁房间。
- **心跳清理**：客户端超过 120s 未发任何消息，服务端主动断开（断开自动触发 `member_left`）。建议客户端每 30s 发一次 `ping`。
- 错误码：`already_in_room` / `room_not_found` / `room_full` / `bad_request`。

## 示例会话

```
A → {"type":"create_room","name":"主持人"}
A ← {"type":"room_created","room_id":"882536419"}
A ← {"type":"joined","room_id":"882536419","member_id":"m1","members":[{...m1...}]}

B → {"type":"join_room","room_id":"882536419","name":"张伟"}
B ← {"type":"joined","room_id":"882536419","member_id":"m2","members":[{...m1...},{...m2...}]}
A ← {"type":"member_joined","member":{...m2...}}

A → {"type":"set_state","mic":false}
A ← {"type":"member_updated","member_id":"m1","mic":false,"cam":true,"sharing":false}
B ← {"type":"member_updated","member_id":"m1","mic":false,"cam":true,"sharing":false}

B → {"type":"chat","text":"大家好"}
A ← {"type":"chat","member_id":"m2","name":"张伟","text":"大家好"}
B ← {"type":"chat","member_id":"m2","name":"张伟","text":"大家好"}

B → {"type":"leave_room"}
A ← {"type":"member_left","member_id":"m2"}

A → {"type":"ping"}   /   A ← {"type":"pong"}
```

## 媒体帧（二进制帧中继）

摄像头/麦克风/屏幕共享通过 **WebSocket 二进制帧** 中继给同会其他成员（服务端透传，不做处理）。

**信封格式**：

```
[4 字节大端 headerLen][header JSON UTF-8][payload]
```

**header**（发送方填写，服务端转发时注入 `member_id`）：

```json
{"kind":"video","w":640,"h":480}
{"kind":"audio"}
{"kind":"screen","w":1920,"h":1080}
```

| kind | payload | 说明 |
|------|---------|------|
| `video` | JPEG 字节 | 摄像头画面，客户端 ~10fps、宽 ≤640 |
| `audio` | PCM（Int16，44.1kHz 单声道） | 麦克风音频块 |
| `screen` | JPEG 字节 | 屏幕共享，~4fps、宽 ≤1280 |

**规则**：
- 服务端校验发送者必须在房间内；注入权威 `member_id` 后转发给同会**其他**成员（不含发送者）。
- 单帧消息上限 8MB。
- 演示级实现，无丢包重传/拥塞控制；视频偶有延迟、音频偶有抖动属正常。
