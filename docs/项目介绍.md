# MeetingGrid — 会议多宫格显示（C++/Qt 6）

> 一套从零实现的多宫格视频会议应用原型：**宫格随成员数量动态调整**，并逐步落地了真实摄像头/麦克风采集、自绘无边框界面、自研 WebSocket 信令服务与媒体帧中继联网。

## 项目简介

MeetingGrid 是一款基于 **C++17 + Qt 6** 的视频会议多宫格界面应用，核心能力是**根据参会成员数量自动计算宫格行列并铺满窗口**。项目按"原型机 → 本地功能落地 → 联网会议"分阶段演进，最终交付了可双机互联的音视频会议演示（摄像头/麦克风/屏幕共享经 WebSocket 帧中继实时同步）。

## 核心亮点

### 1. 动态宫格算法（项目核心）
- 通用公式：`列数 = ⌈√n⌉`，`行数 = ⌈n/列⌉`
- 1 人 → 1×1，2 人 → 1×2，3~4 人 → 2×2，5~6 人 → 3×2，7~9 人 → 3×3 …
- **纯逻辑与 UI 分离**，`GridManager` 独立可测，单元测试覆盖 **0~100 人全量**（含不变量校验）

### 2. 音视频本地闭环真实化
- 主持人宫格接入**真实摄像头**（`QCamera`），设备不可用自动回退模拟画面
- **真实麦克风**采集（`QAudioSource`）+ **RMS 音量 + 滞回阈值**说话检测，说话时绿色高亮
- 摄像头/麦克风开关**真实启停**，关闭即时显示剪影、无残留画面
- Qt 权限自动请求，授权后自动从模拟画面升级为真实设备

### 3. 联网会议（从零到可用，双机互联）
- **自研 WebSocket 信令服务端**（C++/Qt）：建会/入会/退会、成员列表广播、麦摄像共享状态双向同步、聊天中继、心跳清理（120s 超时）
- 客户端接入：真实入会、成员增删实时刷新宫格、状态互见
- **媒体帧中继**：摄像头画面（JPEG）、麦克风（PCM 分块）、屏幕共享（桌面抓帧 JPEG）经服务端透传给同会成员，双机实时可见可听

### 4. 零外部资源依赖
- 全部图标由 `IconFactory` 用 `QPainter` 手绘（麦/摄像/共享/聊天/宫格/结束/地球…），**无任何图片/字体资源文件**，任何环境即开即用

### 5. 无边框自绘窗口
- 去掉系统标题栏，顶栏兼作拖拽区：拖动移动、双击最大化、右键系统菜单
- 自绘最小化/最大化/关闭按钮（悬停高亮、关闭变红）
- 通过 `WM_NCHITTEST` 实现**边缘/四角拖拽缩放**，保留原生缩放光标

### 6. 完整测试体系
- `gridtest`：宫格算法 0~100 人全量单测
- `signalingtest`：进程内启动真实服务端 + 3 个客户端，覆盖建会→入会→状态同步→聊天→退会→关房→**媒体帧中继透传**全流程
- Node 冒烟测试 17 项断言（服务端独立协议回归）

## 功能清单

| 分类 | 功能 |
|------|------|
| 宫格 | 动态行列、宫格/演讲者视图切换、点击切换主画面、成员增减（滑块/预设 1/4/9/16/25） |

| 服务端 | 房间管理、广播、心跳清理、媒体帧中继、控制台日志 |
| 体验 | 无边框自绘窗口、设置面板、会议计时、会议号展示 |

## 运行方式

```bash
build.bat                                    # 构建（客户端 + 服务端 + 测试）
build\MeetingGrid.exe --members=9            # 本地演示：9 人 3×3 宫格
build\server\MeetingGridServer.exe           # 启动信令服务端（默认 0.0.0.0:8090）
build\MeetingGrid.exe                        # 开两个实例 → 联网会议 → 建会/入会
# 双机可见对方摄像头画面、听到麦克风、实时共享屏幕
ctest --test-dir build                       # 全部单元/集成测试
```

## 阶段路线

- ✅ **阶段一** 界面原型机：动态宫格 + 整体 UI
- ✅ **阶段二** 本地功能落地：真实摄像头/麦克风/说话检测/设置面板
- 🔶 **阶段三** 联网会议：信令服务 + 客户端接入 + 媒体帧中继（WebRTC 真低延迟为后续里程碑）
- ⬜ **阶段四** 性能与产品化：大并发优化、崩溃上报、打包发布、多平台
